# 单张知识卡结构

标题：选课，不必困在 CUSIS

## 左侧 · 痛点（约 25%）

- 加载龟速
- 查课复杂
- 冲突难排

使用三个小卡通符号：转圈加载页、堆叠课程卡、碰撞的时间块。

## 中央 · Agent 核心（约 35%）

主文案：Agent 一次处理 1000+ 门课程

四个输入标签：

- 毕业要求
- 资格限制
- 班别时间
- 个人偏好

经过筛选漏斗，输出少量可靠课程组合。

## 右侧 · 理想课表（约 40%）

大卡片（约结果区 2/3）：可视化模式

- 完整课程池
- 资格解释
- 多套周历

小卡片（约结果区 1/3）：纯 Agent 模式

- 对话中直接获得并调整方案

底部总结：更少上课日 · 更多完整自由日
