# 内容分析

- 主题：CoursePlan 如何解决 CUSIS 选课规划痛点
- 内容类型：单张产品 Feature 手绘知识卡
- 受众：需要从大量 CUHK 课程和班别中制定课表的学生，以及关注 Agent 工作流的开发者
- 核心钩子：不是手动在 CUSIS 中逐门查询和反复试冲突，而是让 Agent 一次处理上千门课程
- 必须表达的信息：
  1. 查课繁琐、加载慢；
  2. 班别组合与时间冲突复杂；
  3. Agent 快速处理 1000+ 门课程；
  4. 输出符合毕业要求与个人偏好的理想课表；
  5. 带前端是主要展示模式，纯 Agent 对话也可完整使用。

- 推荐风格：`sketch-notes`
- 推荐布局：`flow` 为主，右端做不对称双出口

## 推荐信息结构

顶部使用一句短标题；主体分成三个连续区块：

1. `CUSIS 查课太折磨`：加载慢、信息散、冲突难排；
2. `Agent 处理 1000+ 门课程`：培养要求、资格、班别和偏好统一筛选；
3. `快速得到理想课表`：左侧较大的前端周历，右侧较小的纯对话结果。

视觉权重约为：痛点 25%，Agent 核心 35%，结果 40%；结果内部再按前端 2/3、纯对话 1/3 分配。
